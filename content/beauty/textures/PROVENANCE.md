# `content/beauty/textures/` — licence and provenance

> M11.c task 6.2. `thirdparty-dependencies`' governance applies to content the project ships as much
> as to code it links, and this is the first content this repository has ever shipped.

## What these files are

Nine PNGs, 256 x 256 each, **generated by this repository** from a seed. They are the source images
for the three materials in [the beauty shot](../../../docs/design/beauty-shot.md); the cooked BC7 and
BC5 blocks the device actually samples are produced at capture time and are not committed.

| file | usage the importer is given | what it holds |
|---|---|---|
| `stone_albedo.png`, `copper_albedo.png`, `gravel_albedo.png` | `colour`, sRGB | base colour |
| `stone_normal.png`, `copper_normal.png`, `gravel_normal.png` | `normal-map`, linear | tangent-space normal, **+Y up** (the OpenGL orientation, which is `mesh.h`'s) |
| `stone_data.png`, `copper_data.png`, `gravel_data.png` | `data`, linear | R roughness, G ambient occlusion, B metalness, A cavity |

## Provenance, and how to check it

They are a pure function of one generator and one seed:

```
python3 tools/content/make_beauty_textures.py --seed 0x5EEDB107
```

- **Generator**: [`tools/content/make_beauty_textures.py`](../../../tools/content/make_beauty_textures.py)
- **Seed**: `0x5EEDB107`
- **Dimensions**: 256 x 256, eight bits a channel
- **Determinism**: integer lattice hashing and double-precision arithmetic, no library random, no
  iteration over an unordered container, and one fixed PNG row filter. Two runs on two machines
  produce identical bytes.

So the record is *checkable* rather than asserted: re-run the generator and compare. A file whose
bytes stop matching what it produces is a file somebody edited by hand, and
`m11c:beauty-textures-are-reproducible` is the criterion that says so.

## Why generated rather than photographed or bought

A texture somebody found has no licence and no provenance that anyone can verify years later, and a
photographed one carries a release and a camera. A generated one carries a file and a number. That is
the whole argument, and it is the same one `tools/content/make_beauty_textures.py`'s own header
makes.

**What it costs, said plainly**: these are procedural materials and they look it. They are a real
albedo, a real tangent-space normal and a real packed data map — block-compressed, mip-chained and
sampled by a compiled material program — and they are not the work of an artist. The rung's claim is
about the PATH, not about the art, and the beauty shot's provenance says which is which.
