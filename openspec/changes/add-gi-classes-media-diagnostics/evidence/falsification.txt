Each was applied to the tree, the named suite rebuilt (dev profile, GCC 13) and run, and the file
restored and md5-verified. Each replaces one exact string; RED lists the test cases that failed.
The device mutations [25]-[27] also regenerated the module's SPIR-V and MSL headers from the mutated
source, ran on the RTX 5060 (Vulkan), and restored the headers. Two first survived and each gained
the check that now kills it: [5] reflection presence (the case compared against the same room a
frame later; it now compares against a twin room at the same frame, whose caches are the room's
bit for bit) and [19] the world tier's update-time cost (the case read it only after a query had
traced world rays; it now reads the profile before any query). [13] first survived because the
fog grid varied along one axis; the grid is now linear in all three and checked against the exact
value between its points. [15] is the leak this change found: on the old visibility term the
divider's face took 0.135 of its probe weight from probes behind it.
