# implement-m11-reach

M11 of the roadmap, and the 1.0 gate: the same project built, cooked, packaged and launched on every
supported target from one recipe — Metal and D3D12 to parity with Vulkan, a native platform backend
proving the porting surface carries no SDL assumption, mobile targets, packaging and patching, the
documentation gate, and **every remaining capability to Complete or explicitly deferred**.

**Opened by M10's closing gate (task 8.5), not yet scoped.** `proposal.md` states what M11 inherits
and what has to be decided before this change can be scoped honestly — first among them whether M11
is one milestone or two. `tasks.md` is the decision list, not an implementation plan.
