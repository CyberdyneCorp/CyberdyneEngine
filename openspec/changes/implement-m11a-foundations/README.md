# implement-m11a-foundations

M11.a of the roadmap: the debts M11 inherits, paid before anything is built on them — the seven
declared gaps that name M11 as their closing rung, an environment field sampled in a shader, the
world demo brought from 122 ms a frame inside its 16.7 ms budget, one CI job that compares two legs'
digests and answers three criteria, and `save-and-persistence` re-scoped rather than demoted a third
time. Carries the split of M11 into five rungs.
