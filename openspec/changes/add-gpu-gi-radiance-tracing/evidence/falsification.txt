render.gi_gpu_tracing, render.gi_gpu, integration.render_gi_pipeline, unit.render_raytracing and
unit.render_graph mutations, Development build, Vulkan on the RTX 5060 (driver 580.95.05). Each
mutation was applied, the gi_gpu SPIR-V/MSL regenerated through shaders/regenerate.py where the
mutation is in a shader, the named suites rebuilt and run, the file restored (headers restored with
it) and the source plus both headers md5-verified against the original. Every case each mutation
turned red is listed under its suite.

m13 first SURVIVED: "a backend's results land on the next update, and every probe is reached" only
asked that every probe become valid, which the priority's age term delivers on its own given time.
The case now measures the longest any probe waits (46 frames against a bound of 90 with the rule,
110 without it), and the record below is the rerun.

Three defects the adversarial review of this change found, each with its regression proven red on
the code before the fix (review-red.txt beside this file): the software tier's grazing scale was a
constant that matched only quarter-metre fields (m17), the probe mirror kept a reconfigured cache's
old probes (m18), and an unconfigured tier batch had zero reach and zero budget (m19).
