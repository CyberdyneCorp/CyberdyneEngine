## A defect this falsification found in the test itself

The first run of b-still-sky stayed GREEN: the wind case compared the centroid's motion with
CY_CHECK_NEAR, which is doctest's Approx with a RELATIVE epsilon, so an epsilon of 64 accepted a
shadow that moved (0, 0) against (1440, -600). The case now compares absolute metres, and the
second run above is red on both axes.
