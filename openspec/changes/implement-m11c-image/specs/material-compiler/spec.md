## ADDED Requirements

### Requirement: A node preview is produced by the compiler, and fails when the compiler is absent
"Node previews use the real compiler" is the requirement; "a preview that looks like a preview" is
the failure mode it exists to prevent. A preview drawn by a second path — a cached thumbnail, an
approximation, a stand-in renderer — would satisfy every observation a person can make of the editor
while making the preview a picture of nothing the frame will run.

A node preview SHALL be generated by compiling that node's sub-graph through the same runtime
compiler that produces the shipping material, and the engine SHALL NOT carry a second path that
produces a preview when that compilation is unavailable.

The claim SHALL be demonstrated as a negative control: with the compiler behind the preview disabled,
the preview SHALL fail visibly and the test that asserts it SHALL go red.

#### Scenario: The compiler is removed from behind the preview
- **WHEN** the runtime compilation path used by previews is disabled
- **THEN** previews SHALL fail rather than fall back, and the test claiming previews use the real
  compiler SHALL go red

#### Scenario: The preview and the shipping material agree
- **WHEN** the same graph is previewed and cooked
- **THEN** the preview SHALL be produced from the same lowering the cooked material is produced
  from, and a divergence SHALL be reported rather than tolerated

### Requirement: The compile report says which inputs are textures and which are constants
A material whose every input is a constant renders, shades and photographs. Nothing in the compiled
artefact today distinguishes it from a fully textured one, so a claim about what a published picture
demonstrates cannot be checked — and this engine's entire published output to date is made of
constant-valued materials, which nobody could have read off the material system.

The compile report SHALL state, per material, which inputs are bound to textures and which are
constants, and the count of each SHALL be readable by a tool without opening the shader source.

#### Scenario: A constants-only material is visible as one
- **WHEN** a material with no texture-bound input is compiled
- **THEN** its compile report SHALL say so, so a picture's material provenance can be stated from the
  artefact rather than from memory

#### Scenario: The report matches what the frame bound
- **WHEN** a frame draws a material and its bindings are inspected
- **THEN** the textures bound SHALL match what the compile report declared, and a mismatch SHALL be
  a failure rather than a diagnostic
