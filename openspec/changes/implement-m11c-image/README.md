# implement-m11c-image

M11.c of the roadmap: the renderer's output rather than its mechanisms — `material-compiler` and
`shader-system` to Complete first, then the eight rows that are the image, plus culling and the sky.
The artefact is an art-directed beauty shot **authored through the tooling that exists rather than
through a material graph editor** — the spike found the editor refusing to open one, this rung built
the vocabulary and the lowering behind it, and the front end that would let a person or a control
socket drive it moved to **M11.e** beside the `.cygraph` writing it depends on (design.md §1.3c). It
is the rung that answers whether this looks like a real engine.
