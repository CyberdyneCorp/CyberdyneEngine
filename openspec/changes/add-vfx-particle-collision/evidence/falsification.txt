# What the first run did not catch, and what changed.
#
# - M4 first replaced the friction expression with `keep = 1.0F`, which left two variables unused
#   and did not build under -Werror; the mutation was respelled to multiply the friction by zero.
# - M5 was GREEN: the stick case read the particle after the gate that stops a stuck particle — and
#   that gate holds a BOUNCED particle still as well. The case now reads the step of contact itself.
# - M10 was GREEN twice. The spark case ran one sub-step a frame, where a cursor is never read; it
#   now runs two. And the first spelling of the mutation only dropped the second sub-step's advance,
#   which three sub-steps would need; the cursor is now mutated where it is read.
# - M11 first deleted the thickness test, which left `thickness` unused and did not build; and no
#   case owned the thickness at all. `a particle further behind a surface than it is thick passes
#   behind it` was written for it.
